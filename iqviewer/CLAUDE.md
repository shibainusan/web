# IQデータを表示するローカルHTMLページ

## このプロジェクトの目的

ローカルのIQデータファイルを読み取り、タイムドメイン波形表示する。
IQデータファイルはfloatの配列で、i,qの並び。

## Text Encoding

All source files must be UTF-8 encoded without BOM (Byte Order Mark).  
PowerShellは基本的にUTF-8 BOMあり で動作するので、テキスト編集には使わない。grep,sedなどのunix系ツール、もしくはPythonスクリプトでテキスト編集すること。
